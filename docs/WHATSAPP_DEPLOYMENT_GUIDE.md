## 3. STEP 2: VERCEL ENVIRONMENT VARIABLES CONFIGURATION

Navigate to **Vercel Project Settings > Environment Variables** and configure the following server-side keys:

| Variable Name | Required | Description | Example / Location |
|---|---|---|---|
| `META_WHATSAPP_PHONE_NUMBER_ID` | Yes | Phone number ID generated by Meta | `109283746501928` (Meta App > WhatsApp > API Setup) |
| `META_WHATSAPP_BUSINESS_ACCOUNT_ID` | Yes | WABA Account ID | `981273645019283` |
| `META_WHATSAPP_ACCESS_TOKEN` | Yes | Permanent System User Token with `whatsapp_business_messaging` | `EAAG...` (Meta Business Settings > System Users) |
| `META_APP_SECRET` | Yes | App Secret for HMAC signature verification | `d7f8...` (Meta App > App Settings > Basic) |
| `META_WHATSAPP_WEBHOOK_VERIFY_TOKEN` | Yes | Custom secret verification string | `nutytales_meta_verify_2026` |
| `META_WHATSAPP_API_VERSION` | Optional | Graph API version | `v21.0` (Default) |
| `WHATSAPP_MOCK_MODE` | Optional | Sandbox simulation toggle | `false` in production; `true` for local tests |

## 4. STEP 3: META DEVELOPER WEBHOOK CONFIGURATION

1. In the Meta Developers App Dashboard, navigate to **WhatsApp > Configuration**.
2. Under **Webhook**, click **Edit**:
   - **Callback URL:** `https://nutytales.com/api/whatsapp/webhook`
   - **Verify Token:** `nutytales_meta_verify_2026` (must match `META_WHATSAPP_WEBHOOK_VERIFY_TOKEN`)
3. Click **Verify and Save**. (The endpoint handles Meta's verification challenge automatically and responds HTTP 200).
4. Under **Webhook Fields**, click **Manage** and subscribe to:
   - `messages` (Inbound customer messages & interactive replies)
   - `message_deliveries` (Sent & Delivered receipts)
   - `message_reads` (Read receipts)
